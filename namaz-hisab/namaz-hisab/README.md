# DeenTogether — একসাথে দ্বীনের পথে

দুইজনের পাঁচ ওয়াক্ত নামাজের হিসাব আর জরিমানার খাতা। Next.js দিয়ে বানানো, মোবাইলের জন্য।

## চালু করবেন যেভাবে

দরকার: Node.js ১৮.১৮ বা তার উপরের ভার্সন।

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন। মোবাইলে দেখতে চাইলে একই ওয়াইফাইতে থেকে `npm run dev -- -H 0.0.0.0` চালিয়ে ফোন থেকে `http://<কম্পিউটারের-আইপি>:3000` খুলুন।

অনলাইনে দিতে চাইলে (ফ্রি): কোডটা GitHub-এ তুলে [vercel.com](https://vercel.com) এ import করলেই একটা লিংক পেয়ে যাবেন, তারপর ফোনের হোম স্ক্রিনে অ্যাড করে অ্যাপের মতো ব্যবহার করা যাবে।

```bash
npm run build   # প্রোডাকশন বিল্ড
npm start       # বিল্ড চালানো
```

## কী কী আছে

- উপরে দুইজনের নাম আর ছবি, পাশে সেই দিনের মোট জরিমানা
- পাঁচটা নামাজের কার্ড, প্রতিটা কার্ড দুই ভাগে ভাগ করা, একেক পাশে একেকজন
- প্রতিটা ট্যাপে টোস্ট মেসেজ আর ছোট একটা সুর (শব্দ বন্ধ করার সুইচ উপরে ডান পাশে)
- একই অপশনে আবার ট্যাপ করলে সেটা বাতিল হয়ে যায়
- আগের দিনের হিসাব দেখা ও ঠিক করা যায়, সামনের দিনে যাওয়া বন্ধ
- মাসের খাতা এক জায়গায়: মাস বদলানোর তীর, দুইজনের মোট টাকা, কোন ওয়াক্তে কে কেমন করল তার ছক, আর পুরো মাসের ক্যালেন্ডার (প্রতিটা দিনে পাঁচটা সরু দাগ = পাঁচ ওয়াক্ত)
- সেটিংসে নাম আর ছবি বদলানো যায়, চাইলে সব হিসাব মুছেও ফেলা যায়
- অ্যাকাউন্ট খুললে ফোন আর ল্যাপটপে একই হিসাব — নিজেদের ডেটাবেসে, বাইরের কোনো লগইন সার্ভিস ছাড়াই

## ডেটা কোথায় থাকে

অ্যাপটা **আগে ব্রাউজারে লেখে, তারপর সার্ভারে মেলায়** — তাই নেট না থাকলেও ট্যাপ করা যায়।

**লগইন ছাড়া।** সব কিছু ব্রাউজারের `localStorage` এ, যেই ডিভাইসে খোলা সেখানেই। দুই ফোনে দুই রকম হিসাব থাকবে, আর ব্রাউজারের ডেটা মুছলে হিসাবও যাবে।

**লগইন করলে।** হিসাব আপনার Neon (Postgres) ডেটাবেসে জমা হয়, তাই ফোন-ল্যাপটপ সব জায়গায় একই খাতা। প্রতিটা দিনের নিজের সময়-ছাপ আছে, তাই দুই ডিভাইসে আলাদা লেখা হলে **যেটা পরে বদলেছে সেটাই টেকে**। উপরের মেঘ আইকনটা বলে দেয় কী অবস্থা — মেলানো হচ্ছে, মিলে আছে, নাকি আটকে গেছে। আইকনে ট্যাপ করলে সাথে সাথে মিলিয়ে নেয়।

লগইনটা এই অ্যাপের নিজের — Firebase, Supabase বা Google-এর কোনো লগইন নেই। পাসওয়ার্ড Node-এর `scrypt` দিয়ে হ্যাশ হয়ে ডেটাবেসে যায়, আর সেশন থাকে একটা httpOnly কুকিতে (ডেটাবেসে শুধু তার sha256, আসল টোকেন কোথাও রাখা হয় না)।

### ডেটাবেস যোগ করবেন যেভাবে

১. [neon.tech](https://neon.tech) এ ফ্রি অ্যাকাউন্ট খুলে একটা প্রজেক্ট বানান।
২. প্রজেক্টের **Connection string** থেকে *Pooled connection* টা কপি করুন।
৩. প্রজেক্ট ফোল্ডারে `.env.local` নামে ফাইল বানিয়ে লিখুন:

```
DATABASE_URL="postgresql://user:pass@ep-xxxx-pooler.region.aws.neon.tech/neondb?sslmode=require"
```

৪. `npm run dev` — টেবিলগুলো প্রথম অনুরোধেই নিজে তৈরি হয়ে যাবে (`lib/db.js` → `ensureSchema`)। হাতে চালাতে চাইলে `db/schema.sql` আছে।

Vercel-এ দিলে একই `DATABASE_URL` টা Settings → Environment Variables এ বসিয়ে দিন।

`DATABASE_URL` না দিলে অ্যাপ ভাঙে না — লগইনের অপশনটাই দেখায় না, আর আগের মতো শুধু ব্রাউজারে হিসাব রাখে। `DATABASE_URL` কখনো ব্রাউজারে যায় না, শুধু সার্ভারে পড়া হয়।

## ফাইলগুলো

```
app/
  layout.js      বাংলা ফন্ট, মেটা ট্যাগ
  page.js        হোম পেজ
  globals.css    পুরো ডিজাইন, রঙ, ইসলামিক প্যাটার্ন
  api/
    auth/[action]/route.js  register / login / logout / me
    hisab/route.js          খাতা নামানো আর জমা দেওয়া
components/
  PrayerApp.js   মূল লজিক, স্টেট, টোস্ট, সিঙ্ক
  PrayerCard.js  এক ওয়াক্তের কার্ড
  MonthReport.js মাসের পুরো হিসাব — মাস বদল, ওয়াক্তের ছক, ক্যালেন্ডার
  SettingsSheet.js নাম, ছবি, শব্দ, অ্যাকাউন্ট, রিসেট
  AuthSheet.js   লগইন আর নতুন অ্যাকাউন্ট
  Toast.js       টোস্ট অ্যালার্ট
  Avatar.js      ছবি বা নামের প্রথম অক্ষর
  Icons.js       সব আইকন
lib/
  prayers.js     নামাজ ও জরিমানার তালিকা
  store.js       localStorage, তারিখ, মাস, বাংলা সংখ্যা
  sound.js       Web Audio দিয়ে বানানো সুর
  db.js          Neon সংযোগ আর টেবিল তৈরি (শুধু সার্ভার)
  auth.js        পাসওয়ার্ড হ্যাশ আর সেশন (শুধু সার্ভার)
  cloud.js       ব্রাউজার থেকে সিঙ্ক, দুই কপি মেলানো
db/
  schema.sql     টেবিলগুলোর সংজ্ঞা
```

জরিমানার অংক বদলাতে চাইলে `lib/prayers.js` এর `STATUSES` এ `fine` এর মান বদলে দিলেই হবে। রঙ বদলাতে চাইলে `app/globals.css` এর একদম উপরের `:root` অংশ।
