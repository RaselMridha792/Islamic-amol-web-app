# DeenTogether — একসাথে দ্বীনের পথে

দুজনে মিলে দ্বীনের ছোট ছোট অভ্যাস ধরে রাখার অ্যাপ। নামাজ, কুরআন, কুইজ, দোয়া আর আমল — সব এক জায়গায়। Next.js দিয়ে বানানো, মোবাইল আগে ভেবে।

## কী কী আছে

**নামাজ** — পাঁচ ওয়াক্তের হিসাব। আপনি নিজেরটা টিক দেন, সঙ্গীরটা শুধু দেখতে পান। মাসের খাতায় মাস বদলানো যায়, কোন ওয়াক্তে কে কেমন করল তার ছক আর পুরো মাসের ক্যালেন্ডার (প্রতিটা দিনে পাঁচটা সরু দাগ = পাঁচ ওয়াক্ত)।

| অবস্থা | জরিমানা |
| --- | --- |
| পড়েছে | ০ |
| কাজা পড়েছে | ৫০ |
| পড়েনি | ১০০ |

**কুরআন** — ১১৪টা সুরা, আরবি + উচ্চারণ + বাংলা অর্থসহ। আয়াত ধরে ধরে বা পুরো সুরা একসাথে "পড়া হয়েছে" চিহ্ন দেওয়া যায়। উপরে দেখায় কয় পারা শেষ হলো, কয় আয়াত পড়া হলো।

**কুইজ** — প্রতিদিন ১০টি প্রশ্ন, প্রতি সঠিক উত্তরে ১০ পয়েন্ট। প্রশ্ন একবার এলে দিনভর একই থাকে, তাই পাতা রিফ্রেশ করে সহজ প্রশ্ন আনা যায় না।

**দোয়া ও আমল** — দরকারি দোয়া (আরবি, উচ্চারণ, অর্থ) আর ছোট ছোট আমলের তালিকা। টিক দিলে পয়েন্ট জমে। রাত ১২টায় (ঢাকার সময়) নতুন করে শুরু।

**আমরা** — দুজনের হিসাব পাশাপাশি। আজকের দিন, কুরআনের অগ্রগতি, মাসের নামাজ, মোট পয়েন্ট।

| --- | --- |
| কুইজের প্রতিটি সঠিক উত্তর | ১০ |
| একটি দোয়া পড়া | ৫ |
| একটি আমল করা | ৫ |

## গোপনীয়তা

**আপনার হিসাব শুধু আপনি আর আপনার সঙ্গী দেখতে পান।** আর কোনো ব্যবহারকারী দেখতে পায় না — কোনো পাবলিক লিডারবোর্ড নেই। সার্ভারের প্রতিটি প্রশ্নে দেখা হয় আপনি কে, আর সঙ্গী ছাড়া অন্য কারও সারি কখনো ফেরত যায় না।

জোড়া বাঁধতে হয় একটা ৬ অক্ষরের কোড দিয়ে — একজন কোড বানান, অন্যজন সেটা লেখেন। কোডের মেয়াদ ২৪ ঘণ্টা। যেকোনো সময় জোড়া খুলে দেওয়া যায়।

## লগইন

লগইনটা এই অ্যাপের নিজের — Firebase, Supabase বা Google-এর কোনো লগইন নেই। পাসওয়ার্ড Node-এর `scrypt` দিয়ে হ্যাশ হয়ে ডেটাবেসে যায়, আর সেশন থাকে একটা httpOnly কুকিতে (ডেটাবেসে শুধু তার sha256, আসল টোকেন কোথাও রাখা হয় না)।

## ডেটা কোথায় থাকে

সব কিছু আপনার নিজের Neon (Postgres) ডেটাবেসে। নামাজের হিসাব **আগে ব্রাউজারে লেখে, তারপর সার্ভারে মেলায়** — তাই নেট না থাকলেও ট্যাপ করা যায়। প্রতিটা দিনের নিজের সময়-ছাপ আছে, তাই দুই ডিভাইসে আলাদা লেখা হলে যেটা পরে বদলেছে সেটাই টেকে।

### চালু করবেন যেভাবে

দরকার: Node.js ১৮.১৮ বা তার উপরে।

১. [neon.tech](https://neon.tech) এ ফ্রি প্রজেক্ট খুলে **Connection string** (Pooled) কপি করুন।
২. `.env.local` ফাইলে লিখুন:

```
DATABASE_URL="postgresql://user:pass@ep-xxxx-pooler.region.aws.neon.tech/neondb?sslmode=require"
```

৩. নির্ভরতা ও কুইজের প্রশ্ন বসান:

```bash
npm install
node scripts/seedQuestions.mjs   # ২৩ হাজারের বেশি প্রশ্ন ঢোকায়, আবার চালালেও ক্ষতি নেই
npm run dev
```

টেবিলগুলো প্রথম অনুরোধেই নিজে তৈরি হয়ে যায় (`lib/db.js` → `ensureSchema`)। হাতে চালাতে চাইলে `db/schema.sql` আছে।

Vercel-এ দিলে **Root Directory** হবে `namaz-hisab/namaz-hisab`, আর `DATABASE_URL` বসবে Settings → Environment Variables এ।

## কুইজের প্রশ্ন কোথা থেকে

দুই উৎস, দুটোই ইচ্ছে করে বেছে নেওয়া যাতে তথ্যগত ভুল না থাকে:

- **যন্ত্রে বানানো (~২৩,৪০০)** — আসল কুরআনের ডেটা থেকে। "এই আয়াতটি কোন সুরার?", "সুরা X এ কয়টি আয়াত?", "কোন পারায়?", "মাক্কি না মাদানি?" ইত্যাদি। উত্তর ডেটা থেকেই আসে, তাই বানানো বা আন্দাজের সুযোগ নেই। `scripts/seedQuestions.mjs`
- **হাতে লেখা (৮০)** — ইসলামের রুকন, নামাজের রাকাত, কুরআনের গঠন, নবী-রাসূল, সীরাত। ইচ্ছে করেই শুধু সেসব বিষয় রাখা হয়েছে যেগুলো নিয়ে মতভেদ নেই; ফিকহের মাযহাব-ভেদে ভিন্ন বিষয়গুলো বাদ। `lib/content/questionsManual.js`

দোয়ার ক্ষেত্রেও একই নীতি — কুরআনের দোয়াগুলোর আরবি, উচ্চারণ ও অনুবাদ যাচাই করা কুরআন ডেটা থেকে টেনে আনা (`scripts/buildDuas.mjs`), হাতে লেখা মাত্র ৭টি ছোট ও অতি পরিচিত হাদিসের দোয়া।

কুরআনের লেখা [quran-json](https://github.com/risan/quran-json) থেকে (বাংলা অনুবাদ: মুহিউদ্দীন খান), আর ৩০ পারার সীমা [alquran.cloud](https://alquran.cloud) API এর সাথে মিলিয়ে দেখা।
