# DeenTogether — একসাথে দ্বীনের পথে

দুইজনের পাঁচ ওয়াক্ত নামাজের হিসাব আর জরিমানার খাতা। Next.js দিয়ে বানানো, মোবাইলের জন্য।

## জরিমানার নিয়ম

| অবস্থা | টাকা |
| --- | --- |
| পড়েছে | ০ |
| কাজা পড়েছে | ৫০ |
| পড়েনি | ১০০ |

## চালু করবেন যেভাবে

দরকার: Node.js ১৮.১৮ বা তার উপরের ভার্সন।

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন। মোবাইলে দেখতে চাইলে একই ওয়াইফাইতে থেকে `npm run dev -- -H 0.0.0.0` চালিয়ে ফোন থেকে `http://<কম্পিউটারের-আইপি>:3000` খুলুন।

অনলাইনে দিতে চাইলে (ফ্রি): কোডটা GitHub-এ তুলে [vercel.com](https://vercel.com) এ import করলেই একটা লিংক পেয়ে যাবেন, তারপর ফোনের হোম স্ক্রিনে অ্যাড করে অ্যাপের মতো ব্যবহার করা যাবে।

```bash
npm run build   # প্রোডাকশন বিল্ড
npm start       # বিল্ড চালানো
```

## কী কী আছে

- উপরে দুইজনের নাম আর ছবি, পাশে সেই দিনের মোট জরিমানা
- পাঁচটা নামাজের কার্ড, প্রতিটা কার্ড দুই ভাগে ভাগ করা, একেক পাশে একেকজন
- প্রতিটা ট্যাপে টোস্ট মেসেজ আর ছোট একটা সুর (শব্দ বন্ধ করার সুইচ উপরে ডান পাশে)
- একই অপশনে আবার ট্যাপ করলে সেটা বাতিল হয়ে যায়
- আগের দিনের হিসাব দেখা ও ঠিক করা যায়, সামনের দিনে যাওয়া বন্ধ
- মাসের খাতা: দুইজনের মোট টাকা, কয় ওয়াক্ত পড়েছে/কাজা/বাদ গেছে, আর দিন ধরে ধরে তালিকা
- সেটিংসে নাম আর ছবি বদলানো যায়, চাইলে সব হিসাব মুছেও ফেলা যায়

## ডেটা কোথায় থাকে

সব কিছু ব্রাউজারের `localStorage` এ, অর্থাৎ যেই ফোন বা কম্পিউটারে খোলা হচ্ছে সেখানেই। কোনো সার্ভারে যায় না, ছবিও না।

মানে হলো দুইজন দুই ফোন থেকে খুললে হিসাব আলাদা হবে। একই হিসাব দুই ফোনে চাইলে Supabase বা Firebase দিয়ে ডেটাবেস যোগ করতে হবে।

## ফাইলগুলো

```
app/
  layout.js      বাংলা ফন্ট, মেটা ট্যাগ
  page.js        হোম পেজ
  globals.css    পুরো ডিজাইন, রঙ, ইসলামিক প্যাটার্ন
components/
  PrayerApp.js   মূল লজিক, স্টেট, টোস্ট
  PrayerCard.js  এক ওয়াক্তের কার্ড
  MonthSummary.js মাসের হিসাব
  SettingsSheet.js নাম, ছবি, শব্দ, রিসেট
  Toast.js       টোস্ট অ্যালার্ট
  Avatar.js      ছবি বা নামের প্রথম অক্ষর
  Icons.js       সব আইকন
lib/
  prayers.js     নামাজ ও জরিমানার তালিকা
  store.js       localStorage, তারিখ, বাংলা সংখ্যা
  sound.js       Web Audio দিয়ে বানানো সুর
```

জরিমানার অংক বদলাতে চাইলে `lib/prayers.js` এর `STATUSES` এ `fine` এর মান বদলে দিলেই হবে। রঙ বদলাতে চাইলে `app/globals.css` এর একদম উপরের `:root` অংশ।
